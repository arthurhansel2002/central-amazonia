# Central Amazônia

Projeto acadêmico de desenvolvimento front-end sobre a Floresta Amazônica, desenvolvido em HTML e CSS.

## Sobre o projeto

O site apresenta informações introdutórias sobre a Amazônia, uma galeria de imagens, um mapa incorporado, curiosidades e um formulário de contato.

## Funcionalidades

- Menu de navegação entre as seções da página.
- Seção informativa sobre a Amazônia.
- Galeria com sete imagens.
- Mapa incorporado do Google Maps.
- Cards com curiosidades.
- Formulário visual de contato.

> Observação: o formulário está implementado visualmente em HTML, mas não possui integração com servidor para enviar mensagens.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Maps incorporado por iframe
